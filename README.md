# slapsec.com

The website of **SlapSec**: strategic advice on technology and cybersecurity. A static site in two languages, English at `/` and Spanish at `/es/`, generated by a small Python build and published as plain files.

## Structure

| Path | What |
|------|------|
| `advisory/copy.json`, `advisory/legal.json` | The only places the words live: the home page and the legal pages |
| `advisory/build_advisory.py` | The build. It writes `publish/` from those two files and the templates beside it |
| `advisory/tools/` | `make_fonts.py` (the cut font files), `make_og.py` (the share images) and `serve.py` (a local server that behaves like the host) |
| `publish/` | **Generated.** What is deployed for slapsec.com. Do not edit it by hand: every build rewrites all of it, including `_headers` (CSP, HSTS and the rest) and `_redirects` |
| `netlify/edge-functions/geo-lang.ts` | Shows visitors browsing from Spain the Spanish page first, unless they chose English |
| `build.py`, `brands/`, `src/`, `publish-thalma/` | The other site built from this repository, with its own sources |
| `netlify.toml` | Host configuration shared by both sites. Each site sets its own publish directory in the host's settings |

## Changing the site

1. Edit `advisory/copy.json` (or `advisory/legal.json`).
2. If the hero headline changed, run `python3 advisory/tools/make_fonts.py` and `python3 advisory/tools/make_og.py`. The italic of its closing clause is a font cut to exactly those letters, and the share images carry the headline. The build stops and says so if the font is out of date.
3. Run `python3 advisory/build_advisory.py`.
4. Look at the result: `python3 advisory/tools/serve.py`, then open http://127.0.0.1:8765/. Add `--geo ES` to browse as a visitor from Spain.
5. Commit the sources and `publish/` together.

`make_fonts.py` needs fontTools with brotli (`pip install fonttools brotli`). `make_og.py` needs Google Chrome.

## Deploy

Continuous deployment from this repository: a push to `main` goes live. Earlier deploys can be restored from the hosting dashboard.
